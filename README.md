# School Dashboard Sidebar

A modern, responsive school dashboard interface built with React, TypeScript, and Tailwind CSS. It features a clean sidebar navigation, dashboard statistics, and school management sections in a user-friendly layout.

## ✨ Features

- Responsive dashboard layout
- Collapsible-style sidebar navigation
- Dashboard statistics cards
- Student and teacher management sections
- Attendance tracking
- Class lists and timetables
- Exams and exam results
- Homework and fee management
- Calendar and news sections
- Settings navigation
- Smooth animations and modern icons

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Iconify / Solar Icons

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Muzaffar-Ameen/SCHOOL-Sidebar.git
```

### 2. Navigate to the project folder

```bash
cd SCHOOL-Sidebar
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.
